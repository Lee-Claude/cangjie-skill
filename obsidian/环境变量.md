# 环境变量

[[AI 工作台]] 全部配置项。写在 `workbench/.env.local`（已在 `.gitignore` 里，不会提交）。改完要重启 dev server。

**全部可选。** 一个都不填也能跑，只是不能对话。

## 模型（二选一，Claude 优先）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | — | 方案 A |
| `ANTHROPIC_MODEL` | `claude-opus-5` | |
| `ANTHROPIC_EFFORT` | `high` | `low`\|`medium`\|`high`\|`xhigh`\|`max` |
| `ANTHROPIC_MAX_TOKENS` | `64000` | thinking 和正文共用，别给小了，见 [[流式对话]] |
| `OPENAI_API_KEY` | — | 方案 B，任何 OpenAI 兼容接口 |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | DeepSeek 填 `https://api.deepseek.com/v1` |
| `OPENAI_MODEL` | `gpt-4o-mini` | |
| `LLM_PROVIDER` | 自动 | `anthropic`\|`openai`，两个都配了才需要 |

## 数据源

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `AIHOT_REPO` | `laolaoshiren/ai-hot` | 见 [[数据源 - AI hot]] |
| `AIHOT_BRANCH` | `main` | |
| `AIHOT_BASE_URL` | — | 直接指定放 `hot.json` / `briefing.json` 的目录 |
| `AIHOT_ENABLED` | `true` | 设 `false` 关掉这个源 |
| `GITHUB_TOKEN` | — | 把 GitHub 搜索限速从 10 次/分钟提到 30 次/分钟 |
| `HOT_RSS_FEEDS` | 量子位 + 机器之心 | 格式 `名称\|地址`，逗号分隔 |
| `HOT_CACHE_TTL_MS` | `300000` | 热点缓存时长，见 [[热点聚合]] |

## 常用组合

**只想白嫖 DeepSeek：**

```bash
OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
```

**只看中文源，关掉英文的：**

```bash
HOT_RSS_FEEDS='量子位|https://www.qbitai.com/feed,机器之心|https://www.jiqizhixin.com/rss'
# Hacker News / GitHub / arXiv 目前是硬编码进 collectors() 的，
# 要关得去 lib/sources/index.ts 里注掉
```

**调试热点源时别让缓存挡路：**

```bash
HOT_CACHE_TTL_MS=0
```
