# 流式对话

[[AI 工作台]] 右半边。像 Claude Code 那样逐字往外蹦，不是等全部生成完再一次性显示。

## 整条链路

```
Messages API (stream)
  → lib/llm/anthropic.ts    消费 SDK 的 event 流，只 yield text_delta
  → app/api/chat/route.ts   包成 ReadableStream，按 SSE 格式往外推
  → hooks/useChat.ts        读 response.body，按 \n\n 切事件，逐块追加
  → components/ChatPanel    React 状态更新，逐字渲染
```

## 服务端

SSE 事件格式定成一个联合类型，前后端共用：

```ts
type ChatStreamEvent =
  | { type: "delta"; text: string }
  | { type: "done"; usage?: { input: number; output: number } }
  | { type: "error"; message: string };
```

三个响应头缺一不可：

```ts
"content-type": "text/event-stream; charset=utf-8",
"cache-control": "no-cache, no-transform",
"x-accel-buffering": "no",   // 关掉 nginx 之类反代的缓冲
```

**`x-accel-buffering: no` 是容易漏的那个** —— 少了它，本地开发一切正常，一上带 nginx 的生产环境流就会被攒成一坨再发，逐字效果直接没了。

用户中途点"停止"时前端 abort，服务端会收到 `AbortError`。这不算错误，静默收尾就行，别往流里塞 error 事件：

```ts
const aborted = err instanceof Error && err.name === "AbortError";
if (!aborted) controller.enqueue(encoder.encode(sse({ type: "error", message })));
```

## Claude 那边的三个坑

代码在 `lib/llm/anthropic.ts`，模型默认 `claude-opus-5`。

**1. 不能传 `temperature` / `top_p` / `top_k`** —— Opus 5 直接返回 400。想调风格只能靠 prompt。

**2. thinking 和正文共用 `max_tokens`。** Opus 5 默认开 adaptive thinking，思考过程也算进这个额度。给小了会出现"思考完发现没配额了"，回答被截断。所以默认给到 64000。

**3. `finalMessage()` 要在流消费完之后才 resolve。** 用它拿 usage：

```ts
const stream = client.messages.stream({ model, max_tokens, system, thinking: { type: "adaptive" }, ... });

for await (const event of stream) {
  if (event.type === "content_block_delta" && event.delta.type === "text_delta") {
    yield event.delta.text;
  }
}
const final = await stream.finalMessage();   // 这里才拿得到 usage
```

## OpenAI 兼容分支

`lib/llm/openai.ts`，用裸 fetch 而不是再装一个 SDK。DeepSeek / Kimi / 通义 / 本地 vLLM 都走这条。

解析上游 SSE 时**必须处理跨 chunk 的半截事件** —— 网络分片不会正好落在事件边界上：

```ts
buffer += decoder.decode(value, { stream: true });
const events = buffer.split("\n\n");
buffer = events.pop() ?? "";     // 最后一段可能不完整，留到下一轮
```

前端 `useChat` 里是同一套逻辑。单个 chunk JSON 解析失败就跳过，不要让整条流挂掉。

## Provider 选择

`LLM_PROVIDER` 显式指定，否则谁有 key 用谁，Claude 优先。两个都没有就抛 `MissingApiKeyError`，路由返回 428，前端顶部显示配置提示条 —— 这样没 key 的人打开也能看热点，不会一片空白。
