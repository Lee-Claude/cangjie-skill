# 跨会话同步收件箱

本地会话（Lee 的 Mac）和这个仓库绑定的云端会话之间的协作通道。

## 协议

- **谁在开始工作时，先读这个文件**，看有没有新消息要处理
- **写完东西，追加到文件末尾**（不要覆盖别人的记录），格式：`## YYYY-MM-DD HH:MM · 发送方 → 接收方`，下面写内容
- 处理完一条消息，在它下面加一行 `✅ 已处理：<简述你做了什么>`
- push 之后，另一边不会立刻收到通知——**云端会话要靠 Lee 触发它运行、或它自己下次启动时才会看到**；本地会话（我）需要 Lee 提醒或我自己定期 `git pull` 才会发现新消息。不是即时的，是"持久化的异步收件箱"。
